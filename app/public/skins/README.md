# Скины CaseFlow

Настройки оформления находятся в этом каталоге:

- `catalog.js` — варианты оформления, подписи, логотипы, светлый/тёмный режим и набор доступных элементов управления. Меню строится из каталога.
- `tokens.css` — цвета, шрифты, скругления и тени. Именованные параметры (`--apple-accent`, `--apple-page-bg`, `--font` и др.) задают основные роли. Нумерованные параметры сохраняют точные значения прежних стилей. Чтобы изменить конкретный элемент, найдите имя его параметра в правиле компонента и переопределите его в блоке нужного скина. Изменение общего значения в `:root` затрагивает все его применения.
- `icons.svg` — общие пиктограммы по назначению: обновление, сохранение, удаление и т. д. Новый набор можно назначить через свойство `icons` в записи скина. В таком наборе нужно сохранить идентификаторы `skin-icon-…`.

Для нового варианта добавьте запись в каталог, укажите классы существующего профиля и уникальный класс, затем переопределите нужные параметры в `tokens.css`. Новый профиль с иной структурой элементов потребует правил компонентов; простая смена цветов и значков — нет. Служебная геометрия диаграмм, кольца загрузки и иллюстрации заглушки не является частью набора пиктограмм.

При добавлении компонентов не задавайте цвет прямо в CSS-компоненте. Сначала проверьте, есть ли подходящая роль. Для действий используйте существующий символ SVG, а не отдельную копию контура. Проверка: `node --test app/test/skins.test.mjs` из корня проекта.
