# MVP распределения нагрузки — версия для GitHub Codespaces

Эта папка — отдельная переносимая копия проекта для временного запуска через GitHub Codespaces.

Локальная рабочая версия проекта находится вне этой папки и не зависит от этих настроек.

## Как это работает

```text
GitHub repo → Codespace → Node-сервер → ссылка вида *.app.github.dev
```

Приложение хранит данные в Excel-файле:

```text
app/data/raspredelenie_storage.xlsx
```

Справочник ЮЦ/регионов:

```text
app/справочники.xlsx
```

## Быстрый запуск в GitHub Codespaces

1. Создайте новый GitHub-репозиторий.
2. Загрузите содержимое этой папки в корень репозитория.
3. На GitHub нажмите:

```text
Code → Codespaces → Create codespace on main
```

4. Codespace автоматически выполнит:

```text
cd app && npm install
```

5. После старта контейнера сервер запустится в фоне на порту `8766`.
6. Во вкладке `Ports` откройте порт `8766`.
7. Если нужно дать доступ другим пользователям, смените видимость порта:

```text
Private → Public
```

После этого ссылка будет выглядеть примерно так:

```text
https://...-8766.app.github.dev
```

## Ручной запуск, если сервер не стартовал автоматически

В терминале Codespaces:

```bash
cd app
npm install
npm run start:codespaces
```

Затем открыть порт `8766` во вкладке `Ports`.

## Остановка по бездействию

GitHub Codespaces сам останавливает среду после периода бездействия. Таймаут можно настроить в настройках GitHub Codespaces.

Если нажать кнопку `Выход` внутри приложения, остановится только Node-сервер приложения. Сам Codespace останется существовать, пока GitHub не остановит его по таймауту или пока вы не остановите его вручную.

## Важное ограничение по данным

Это временный/демонстрационный вариант.

Excel-файл хранится внутри Codespace. Чтобы не потерять изменения:

- после рабочей сессии скачивайте `app/data/raspredelenie_storage.xlsx`; или
- коммитьте изменённый Excel-файл обратно в GitHub; или
- используйте этот вариант только как тестовый стенд.

Для постоянной эксплуатации лучше перенести хранение из Excel в базу данных.
