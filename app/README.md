# HTML-приложение распределения нагрузки

Локальное MVP-приложение работает по схеме:

```text
браузер → локальный Node-сервер → Excel-хранилище
```

Excel остаётся файлом хранения данных:

```text
app/data/raspredelenie_storage.xlsx
```

## Как запустить

Из корневой папки проекта `/Users/sergd/Documents/Work/MVP распределение`:

```bash
./start_app.sh
```

Либо напрямую из папки приложения:

```bash
cd app
/Users/sergd/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node server.mjs
```

После запуска открыть в браузере:

```text
http://127.0.0.1:8766
```

## Как выйти

В интерфейсе нажать кнопку `Выход` в правом верхнем углу. Приложение отправит команду остановки локальному серверу и попробует закрыть вкладку браузера.

Если браузер не разрешит закрыть вкладку автоматически, сервер всё равно будет остановлен, а вкладку можно закрыть вручную.

## Как пересоздать Excel-хранилище из текущих данных

Если нужно заново перенести данные из существующего Excel:

```bash
cd app
/Users/sergd/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node scripts/create-storage.mjs
```

Это перезапишет:

```text
app/data/raspredelenie_storage.xlsx
```

## Основной сценарий работы

1. Открыть вкладку `Распределение`.
2. Заполнить тип дела, предмет, регион, стороны и дату поступления.
3. Нажать `Получить рекомендацию`.
4. Если кандидат подходит — нажать `Подтвердить автоназначение`.
5. Если требуется исключение — выбрать `Ручной ответственный`, заполнить комментарий и нажать `Назначить вручную`.

## Как распределить уже заведённое дело

Если дело уже есть в реестре и находится в статусе `Ожидает распределения`, повторно заводить его через карточку `Распределение` не нужно.

1. Открыть вкладку `Дела`.
2. Найти строку дела.
3. В колонке `Действие` нажать:
   - `Авто` — программа проверит очередь и назначит дело по тем же правилам, что и новое дело;
   - `Вручную` — руководитель выбирает ответственного и обязательно указывает комментарий.

Кнопки появляются только у дел без ответственного в статусе `Ожидает распределения`. Назначение меняет существующую строку Excel, а не создаёт дубль.

В этой же вкладке можно открыть карточку дела кликом по `CASE-XXXX`.

Если нужно принудительно поменять ответственного или статус, включите тумблер `Редактирование дел`. После выбора нового значения в колонке `Действие` появятся две кнопки: зелёная `✓` сохраняет изменение, красная `×` отменяет его. Смена ответственного пишется в журнал как ручная операция и не двигает очередь.

## Сотрудники и отпуска

Вкладка `Сотрудники` разделена на два режима:

1. `Доступность в очередях` — временное включение/выключение сотрудника полностью или по конкретным типам нагрузки.
2. `Отпуска` — годовой календарь отпусков по выбранному сотруднику.

В `Доступности в очередях` поле `Активен = Нет` временно исключает сотрудника из всех автоматических очередей. Поля `Суд`, `Админ`, `Претензии` при этом становятся недоступными для редактирования, но их значения не стираются. Если вернуть `Активен = Да`, сохранённая специализация снова начинает работать.

На вкладке `Отпуска`:

- выберите сотрудника и год;
- включите тумблер `Редактирование отпусков`;
- в режиме `Один день` клик по дате ставит или снимает отпуск;
- в режиме `Поставить диапазон` первый клик выбирает начало, второй — конец периода;
- в режиме `Снять диапазон` первый клик выбирает начало, второй — конец периода, который нужно очистить;
- кнопка `Очистить год` снимает все отпуска сотрудника за выбранный год после подтверждения.

Отпуска сохраняются в отдельном листе Excel-хранилища:

```text
Отпуска
```

Алгоритм распределения проверяет отпуск сотрудника на дату назначения и пропускает сотрудника, если эта дата отмечена в календаре отпусков.

## Реализованные правила

- Отдельные очереди для `претензия`, `административное`, `судебное`.
- Тип нагрузки `спецсуд` не используется.
- Регионы в делах приводятся к названиям из `справочники.xlsx`, например `Хабаровск` → `Хабаровский край`.
- Два дела подряд одного типа не назначаются одному сотруднику автоматически.
- Ручное назначение может отступить от этого правила, но комментарий обязателен.
- Отпуск исключает сотрудника из автоматического назначения.
- Долг после отпуска хранится в очереди и ограничен значением `1`.
- Активное число используется только для расчёта нагрузки, не как лимит.

## Важно

Пока приложение сохраняет изменения в Excel, лучше не держать файл `raspredelenie_storage.xlsx` открытым в Excel, чтобы не получить конфликт записи.
